📱 FitTracker
📝 Descrição

O FitTracker é uma aplicação Windows Forms desenvolvida em C#, que permite aos utilizadores registar, monitorizar e analisar as suas atividades físicas.

Com uma interface de navegação lateral moderna e intuitiva, a aplicação disponibiliza várias ferramentas para acompanhar o progresso ao longo do tempo.

🚀 Funcionalidades Principais
🔐 Autenticação de Utilizadores
Sistema de registo e login com acesso personalizado.

📊 Dashboard Interativo
Visualização gráfica da atividade física semanal.

🏋️‍♂️ Gestão de Treinos
Possibilidade de adicionar, editar e remover registos de atividades físicas.

🎯 Definição de Objetivos
Estabelecimento de metas de treino com datas limite.

👤 Perfil de Utilizador
Gestão de informações pessoais como nome e password.

📈 Estatísticas Visuais
Análise de progresso com gráficos de barras dinâmicos.

🧰 Tecnologias Utilizadas
Linguagem: C#

Framework: .NET Framework 4.7.2

Interface Gráfica: Windows Forms

Base de Dados: SQL Server LocalDB

Bibliotecas:

Guna UI2 WinForms

System.Data.SqlClient

System.Windows.Forms.DataVisualization

💻 Requisitos do Sistema
Sistema Operativo: Windows 10 ou superior

Framework: .NET Framework 4.7.2 ou superior

Base de Dados: SQL Server LocalDB 2019 ou superior

Memória: Mínimo 4 GB de RAM

Armazenamento: Cerca de 1 GB de espaço em disco

🛠️ Instalação
Clone o repositório:
git clone <link-do-repositório>

Abra a solução:
FitTracker.sln no Visual Studio

Restaure os pacotes NuGet:
Através do Package Manager

Configure a base de dados:
Certifique-te que o SQL Server LocalDB está instalado e a correr.

Atualize a string de conexão:
No ficheiro de configuração da aplicação.

Compile e execute a aplicação

📌 Como Usar
Inicia a aplicação.

Cria uma nova conta ou faz login com as tuas credenciais.

No Dashboard Principal, visualiza o teu progresso e estatísticas.

Utiliza o menu lateral para navegar entre as diferentes opções:

➕ Adicionar novo treino

🎯 Definir objetivos

✏️ Editar treinos existentes

❌ Remover treinos

👤 Gerir perfil
