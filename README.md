# 📱 FitTracker

### 📝 Descrição

O **FitTracker** é uma aplicação **Windows Forms** desenvolvida em **C#**, que permite aos utilizadores **registar**, **monitorizar** e **analisar** as suas atividades físicas.

Com uma **interface de navegação lateral moderna e intuitiva**, a aplicação disponibiliza várias ferramentas para acompanhar o progresso ao longo do tempo.

---

### 🚀 Funcionalidades Principais

- 🔐 **Autenticação de Utilizadores**  
  Sistema de **registo e login** com acesso personalizado.

- 📊 **Dashboard Interativo**  
  Visualização **gráfica** da atividade física semanal.

- 🏋️‍♂️ **Gestão de Treinos**  
  Possibilidade de **adicionar**, **editar** e **remover** registos de atividades físicas.

- 🎯 **Definição de Objetivos**  
  Estabelecimento de **metas de treino** com datas limite.

- 👤 **Perfil de Utilizador**  
  Gestão de **informações pessoais** como nome e password.

- 📈 **Estatísticas Visuais**  
  Análise de progresso com **gráficos de barras** dinâmicos.

---

### 🧰 Tecnologias Utilizadas

- **Linguagem:** C#
- **Framework:** .NET Framework 4.7.2

- **Base de Dados:** SQL Server LocalDB
